# App By Franmax

Juego familiar de categorías: 100 tarjetas aleatorias sin repetir, contador de progreso y diseño adaptable a celulares.

## Cómo jugar

1. Tocá **Sacar tarjeta**.
2. Todos piensan una respuesta para la categoría.
3. Cuando terminen, pasen a la siguiente.

## Publicar en GitHub Pages

1. Subí el proyecto a un repositorio en GitHub.
2. Andá a **Settings → Pages → Build and deployment → Source** y elegí **GitHub Actions**.
3. Cada vez que subas cambios a la rama `main`, el sitio se publica automáticamente.

El flujo de publicación está en `.github/workflows/deploy.yml`.
